# 🩺 Diabetes Diagnostic Engine & AI Clinical Copilot

An interactive health analytics and risk assessment platform combining classical supervised machine learning with a conversational AI assistant. Built with Reflex for a reactive 3D interface and powered by the Groq API for rapid clinical guidance.

---

## 🚀 Live Demo & Preview
- **Live Web Application:** [Launch Live App](https://your-deployment-link-here)

---

## 📌 Key Highlights
- **Risk Stratification:** Classifies patient diabetes risk based on diagnostic indicators (glucose levels, BMI, insulin levels, age, and blood pressure).
- **AI Consultation Copilot:** Employs an LLM via Groq API to interpret risk scores and provide actionable, context-aware health insights.
- **3D Interactive Interface:** Responsive, modern user experience designed natively in Reflex.
- **Fast Inference:** Ultra-low latency chat responses powered by Groq's LPU inference engine.

---

## 🛠 Tech Stack
- **Languages:** Python
- **Full-Stack & UI:** Reflex (Python full-stack framework)
- **Machine Learning:** Scikit-Learn, NumPy, Pandas
- **LLM & Copilot:** Groq API (Llama 3 / Mixtral endpoints)
- **Deployment:** Reflex Cloud
